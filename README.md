# StreamMesh

**StreamMesh** is a scalable, event-driven video streaming platform built using Spring Boot and microservices architecture. It focuses on asynchronous video processing, adaptive streaming, and distributed systems.

## Tech Stack

- **Backend:** Java, Spring Boot, Spring Cloud
- **Messaging:** Apache Kafka
- **Database:** PostgreSQL
- **Caching:** Redis
- **Cloud Storage:** AWS S3
- **Video Processing:** FFmpeg
- **Streaming Protocol:** HLS (HTTP Live Streaming)
- **Containerization:** Docker

## Planned Features

- Video upload and storage
- Asynchronous video processing using Kafka
- Video transcoding into multiple resolutions
- HLS-based adaptive video streaming
- Video metadata management
- Redis caching
- Microservices-based architecture
